
# Global Patent Intelligence Data Pipeline

A data engineering project that collects, cleans, stores, and analyzes real-world patent data from PatentsView (USPTO).

## Setup
```bash
pip install -r requirements.txt
```

## Run Pipeline
```bash
python scripts/pipeline.py
```

## Run Dashboard
```bash
streamlit run scripts/dashboard.py
```

## Data Source
PatentsView Granted Patent Disambiguated Data:
https://data.uspto.gov/bulkdata/datasets/pvgpatdis
